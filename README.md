📈 Trading Journal and Performance Analyzer

📌 Project Overview

The Trading Journal and Performance Analyzer is a full-stack web application designed to help traders record, manage, track and analyze their trading activities.

The application provides a centralized platform where traders can maintain trade records, monitor performance, analyze trading patterns and evaluate their trading strategies.

🎯 Problem Statement

Many retail traders struggle to maintain proper trading records and evaluate their trading performance. Without structured trade tracking and performance analysis, traders may find it difficult to identify mistakes, understand their strengths and improve their trading strategies.

💡 Proposed Solution

A web-based Trading Journal that allows users to record their trades and automatically analyze trading performance through an interactive dashboard with visual analytics.

✨ Key Features

- User registration and login.
- Secure authentication using JWT.
- Add, edit and delete trade records.
- Store detailed trading information.
- Track profit and loss.
- Calculate trading win rate.
- Analyze average risk-to-reward ratio.
- Identify best and worst trades.
- Interactive performance dashboard.
- Equity curve visualization.
- Search and filter trading records.
- Responsive user interface.

📊 Performance Analytics

The dashboard provides important trading performance metrics:

1. Win Rate: Percentage of profitable trades.
2. Total Profit/Loss: Overall trading performance.
3. Average Risk-to-Reward: Average risk-to-reward ratio across trades.
4. Best Trade: Highest-performing trade.
5. Worst Trade: Lowest-performing trade.
6. Equity Curve: Visual representation of account growth over time.

🏗️ Project Architecture

The application follows a full-stack architecture:

- Frontend: Provides the user interface for managing trades and viewing analytics.
- Backend: Handles authentication, trade management and business logic.
- Database: Stores user accounts and trading records.
- Analytics: Processes trade data and generates performance visualizations.

⚙️ Installation and Setup

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project directory

cd trading-journal

3. Create a virtual environment

python -m venv venv

4. Activate the virtual environment (Windows)

venv\Scripts\activate

5. Install dependencies

pip install -r requirements.txt

6. Configure PostgreSQL

Create a PostgreSQL database named:

CREATE DATABASE trading_journal;

Configure your database connection and environment variables before starting the application.

7. Run the Flask application

python app.py

Note: Update the startup command if your Flask entry-point filename is different.
